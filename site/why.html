skill-flow
Why How Catalog Start GitHub

The failure mode we refuse

Expertise trapped in zip files and tribal paths.

Every harness wants SKILL.md somewhere different. Teams paste skills by hand, skip audits, and lose track of what agents can load.

Without skill-flow

  • Manual drag-drop into one client only
  • No shared gallery across the team
  • Unvetted scripts inside “helpful” skills
  • OpenCode / Cursor / Codex never share a library

With skill-flow

  • Search → show → audit → install
  • Adapters for native harness paths
  • Portable .agents/skills default
  • Confirm required; scripts never run by the plane

Skills teach agents how. MCP connects agents to things. skill-flow is the install plane for skills.
