Quickstart

Run skill-flow locally

Node.js ≥ 22. Git on PATH for remote installs.

Install & seed
git clone https://github.com/real-limitless/skill-flow.git
cd skill-flow
npm install && npm run build
npm run catalog:seed

npx skill-flow doctor
npx skill-flow catalog search commit
npx skill-flow install seed:hello-skill --target portable --yes
npx skill-flow serve
MCP config snippet
{
  "mcpServers": {
    "skill-flow": {
      "command": "npx",
      "args": ["skill-flow", "serve"]
    }
  }
}
