skill-flow
Why it exists Skill sprawl

The failure mode we refuse

Expertise trapped in zip files and tribal paths.

Every harness wants SKILL.md in a different folder. Teams paste skills by hand, skip audits, and lose track of what agents can load. That is not a control plane.

Without skill-flow

  • Manual drag-drop into ~/.claude/skills only
  • No shared gallery — each laptop a different set
  • Unvetted scripts and prompt injections in “helpful” skills
  • OpenCode / Cursor / Codex never see the same library

With skill-flow

  • One catalog: search, show, audit before install
  • Adapters write native paths for each harness
  • Portable .agents/skills default for multi-agent teams
  • Install requires confirm — scripts never run by the plane
Why you need it
You want agents with specialized skills — not a folder of unknown markdown nobody audited.
