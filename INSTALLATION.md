# Installation

Source: private kit TheFLOW. Family ritual: clone DEVELOPMENT, then Compose.

This CORE branch is documentation only.

```sh
git clone -b DEVELOPMENT https://github.com/real-limitless/skill-flow.git
cd skill-flow
docker compose up -d --build
```

Health and doctor: port 8788.

Host Node (`npx skill-flow`) is for contributors. It is not the supported run path.
